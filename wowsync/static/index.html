Your machines

Run WoWSync on each machine, then pair using its address and private token.

Use this token when adding this machine from another device. Anyone with it can read the supported game folders.

For peer access, start with --listen 0.0.0.0. Tailscale encrypts traffic between machines; plain LAN HTTP does not.

Backup history

Each sync backs up files before writing. Restore is blocked if the files have changed since.
